- **Simpler accounts.** One account per browser. The sign-in page offers "New here? Create an account"; turn it off with `SPUR_DISABLE_SIGNUP=true`. This replaces 1.0.1's account switching and admin settings.
- **Account creation fixed.** It no longer fails after the first account is made, and an old `.env` with `SPUR_ALLOW_SIGNUP=false` no longer hides it (that setting is not read any more).
- **Usernames can be email addresses.**
- **Light/dark button** in the header, kept in step with Settings → Appearance.
- **Big screens are filled** edge to edge; Settings uses three columns from 1800 px.

Upgrading: in your spur folder run `git pull` then `docker compose up -d --build`. Accounts and runs are kept.
